# Description
Application complet web et mobile permettant de suivre les travaux routières utlisant spring boot pour la version web et ionic avec vue pour le mobile

# Instruction docker
## Telecharger les données osm
Mettre le fichier osm d'Antananarivo ou Madagascar dans cartes/data/osm/madagascar-latest.osm.pbf
## Deploiement docker
Lancer la commande dans la racine du projet : docker compose up -d
